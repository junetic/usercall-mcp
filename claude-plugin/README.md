# Usercall: User Interviews

AI-moderated user interviews and qualitative research for Claude.

Usercall helps you understand why users behave the way they do. Create an interview study from a research question, test the questions, optionally prepare an invite inside the product, and bring back themes and quotes from completed interviews.

## What you get

- Remote MCP tools at `https://mcp.usercall.co` (OAuth)
- Skills (copies of the repo root `skills/` files; `pnpm plugin:check` fails if they differ):
  - `run-user-research`: broad interview and qualitative research asks
  - `investigate-product-friction`: churn, abandonment, stuck flows
  - `investigate-user-behavior`: spikes, drops, cohort differences
  - `validate-with-users`: evidence before product, UX, or pricing decisions
